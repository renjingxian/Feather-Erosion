个人介绍

大家好，我是《羽蚀纪》项目组的成员之一。 在本次项目中，我主要负责网站的前端开发以及部分游戏功能的设计与实现。 在项目开始之前，我对网页开发只有一些基础了解， 因此这次项目也是我进一步学习 HTML、CSS 和 JavaScript 的过程。

从最开始搭建网站页面，到之后完成登录注册、游戏主菜单、 剧情阅读页面以及不同页面之间的跳转， 我逐渐熟悉了一个完整网页项目的基本开发流程。 在开发过程中，我也遇到了文件路径、页面布局、 JavaScript 逻辑和 GitHub 协作等问题。 通过不断调试和修改，我开始更加重视代码结构和可维护性， 也希望最终能让《羽蚀纪》成为一个具有一定沉浸感的互动故事作品。

项目工作

  • 搭建和调整网站部分页面结构
  • 完成登录、注册及游戏主菜单页面
  • 编写并调整 HTML、CSS 和 JavaScript
  • 实现剧情文本动态显示功能
